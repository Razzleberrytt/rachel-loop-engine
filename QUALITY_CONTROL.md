# Final Quality Control

A variant fails if any hard gate fails.

## Hard gates

- [ ] No fabricated or misleading meaning created by edits
- [ ] No accidental exposure of sensitive personal information
- [ ] Speech remains understandable
- [ ] Captions match the audible speech closely
- [ ] Key faces/actions are not blocked by captions or UI-safe-zone mistakes
- [ ] No broken/black frames
- [ ] No abrupt audio click/pop at ordinary cuts
- [ ] If looping: semantic meaning remains intact
- [ ] If looping: transition reviewed across at least 3 cycles

## Retention gates

- [ ] First second has a clear purpose
- [ ] No removable camera-settling intro
- [ ] No obvious dead tail
- [ ] No repeated explanation without payoff
- [ ] Payoff survives the tightening
- [ ] Ending type is intentional

## Authenticity gates

- [ ] Rachel still sounds like Rachel
- [ ] Timing does not feel unnaturally compressed
- [ ] Effects do not dominate the moment
- [ ] Reactions have not been contextually misrepresented

## Visual gates

- [ ] 9:16 crop preserves important action
- [ ] Punch-ins are motivated
- [ ] No excessive zoom jitter
- [ ] Captions stay in safe area

## Audio gates

- [ ] Dialogue level is consistent
- [ ] Noise reduction is not metallic/robotic
- [ ] Music, if present, stays under dialogue
- [ ] Loop ambience is continuous enough not to reveal restart

## Final scores (1–5)

Record:
- Hook strength
- Clarity
- Authenticity
- Pacing
- Payoff
- Loop quality (if applicable)
- Overall confidence

Any dimension <=2 triggers manual review before publishing.
