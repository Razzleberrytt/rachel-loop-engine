# Lessons Learned

This file contains validated learnings promoted from experiments.

## Promotion standard

A lesson should not become a canonical Rachel rule because of a single high-view video. Prefer:
- repeated performance across several posts;
- A/B-like comparisons where possible;
- consistency across comparable content types;
- a plausible causal editing mechanism.
