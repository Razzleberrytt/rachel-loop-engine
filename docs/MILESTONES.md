# Milestones

## M1 — Operational Editing Brain ✅
Versioned Rachel-specific creative rules, retention rules, loop playbook, prompts, and QC principles.

## M2 — Executable Orchestration ✅ foundation
- durable job/source/variant/QC models
- JSON manifests
- deterministic dry-run validation
- editor transport protocol
- Descript adapter coordinator
- mock transport
- CLI
- CI tests

## M2.5 — Live Descript Bridge ⏭
Wire the connected Descript tool calls into `EditorTransport`, then run the first real raw-video job end-to-end.

## M3 — Automatic Multi-variant Production ✅ coordinator
Create/derive A Natural, B Retention, C Loop compositions, resolve their real IDs from project inspection, and publish selected variants.

## M4 — Analytics Learning Loop 🟡 foundation
Ingest retention/replay/completion metrics, compare variants, and promote repeatable wins only after an evidence gate.

## M5 — Drop-folder / one-button intake
A raw video landing in the intake location creates a job automatically and returns finished outputs plus a concise review card.
