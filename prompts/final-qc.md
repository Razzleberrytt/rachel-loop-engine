# Final QC Prompt

Audit the exported candidate against `QUALITY_CONTROL.md`.

Watch from the perspective of a first-time viewer, then inspect the ending/restart separately.

Return:
- PASS / REVIEW / FAIL
- hard-gate failures
- removable seconds or frames
- confusing cuts
- caption mistakes
- crop/subject problems
- audio artifacts
- authenticity concerns
- loop seam issues
- 1–5 scores for hook, clarity, authenticity, pacing, payoff, loop quality, overall confidence

Do not approve a technically polished edit if it damages the underlying moment.
