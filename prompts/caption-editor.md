# Caption Editor Prompt

Create captions that improve comprehension without becoming the main visual event.

Rules:
- Correct transcription errors using audible evidence.
- Use phrase-level chunks by default.
- Break lines at natural linguistic boundaries.
- Keep text away from faces, hands, and platform UI zones.
- Emphasize only high-value words.
- Do not add claims or context that were not spoken/shown unless explicitly requested as editorial text.
- Ensure the final caption does not expose the loop seam unnecessarily.
